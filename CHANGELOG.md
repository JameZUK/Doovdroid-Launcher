# Changelog

## 0.2 — 2026-11-11

- **Speed-dial editor** in the admin menu: add people from Contacts, move them up and down, remove
  them. Saves straight to the settings file.
- Admin screens share one layout with a soft-key bar.

## 0.1 — 2026-11-11

First version.

- One-screen home: clock, up to 8 people, Messages, WhatsApp, Recent calls, Contacts. Keypad only,
  touch ignored, sized to always fit.
- Dialling by typing digits; hold 0 for +; emergency numbers open the dialler.
- Unread texts, WhatsApp count and missed calls on their rows.
- Soft-key bar naming what the two blank keys do.
- Admin menu behind `0000` + PIN, unlocking Settings for 15 minutes.
- The guard: closes the notification pull-down, keeps hidden apps away, returns to the home screen
  when the screen goes off.
- Phone setup and restore scripts.
- Three screen colour schemes.
